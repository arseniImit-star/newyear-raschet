# Расчёт количества дней до нового года
Приложение создано для расчёта количества календарных дней до Нового года
от заданной даты, либо от текущей даты сервера.

## Требования
Go версии 1.22 и выше.
Git
## Установка и запуск
Запуск напрямую:

```bash
go run ./cmd/server
```
## Cборка
```bash
go build -o app.exe ./cmd/server
.\app.exe
```
Сервер запускается по адресу
```bash
http://localhost:8080
```
## Тестирование
Для запуска тестов надо выполнить команду:
```bash
go test -v ./...
```
## Документация API
HTTP-сервис предоставляет эндпоинт, через который можно
получить число календарных дней, оставшихся до ближайшего 1 января.
### `GET /api/v1/countdown`
Считает дни либо от текущего момента, либо от явно переданной даты
## Параметры запроса
Сервис принимает один необязательный query-параметр:

date — дата отсчёта в формате YYYY-MM-DD (например, 2024-12-31).
Если параметр не передан, используется текущая дата сервера в UTC.

Другие параметры игнорируются. Метод запроса должен быть GET —
при любом другом сервис вернёт 405 Method Not Allowed.
### Query-параметры

| Параметр | Тип      | Обязательный | Формат       | Описание                                                                                             |
| :------- | :------- | :----------: | :----------- | :--------------------------------------------------------------------------------------------------- |
| `date`   | `string` |     Нет      | `YYYY-MM-DD` | Дата, относительно которой выполняется расчёт. Если параметр не указан, расчёт производится относительно текущей даты сервера. |

Посторонние параметры игнорируются. Эндпоинт принимает только `GET`:
для любого другого метода ответ будет `405 Method Not Allowed`.

### Примеры

Считаем от сегодняшнего дня:

```bash
curl "http://localhost:8080/api/v1/countdown"
```

Ответ:

```json
{"date":"2025-06-15","days_until_new_year":200}
```

Считаем от конкретной даты:

```bash
curl "http://localhost:8080/api/v1/countdown?date=2024-12-31"
```

Ответ:

```json
{"date":"2024-12-31","days_until_new_year":1}
```

Некорректный формат:

```bash
curl -i "http://localhost:8080/api/v1/countdown?date=invalid-date"
```

Ответ:

```http
HTTP/1.1 400 Bad Request
Content-Type: application/json; charset=utf-8

{"error":"invalid date, expected YYYY-MM-DD"}
```

> В PowerShell нужно писать `curl.exe`: короткое `curl` — это алиас на
> `Invoke-WebRequest`, и вывод будет другим.

### Формат ответа

Успешный ответ — `200 OK`, `Content-Type: application/json; charset=utf-8`.
Тело — объект с двумя полями:

- `date` — дата, от которой считали, в формате `YYYY-MM-DD`;
- `days_until_new_year` — целое число дней до 1 января следующего года.

Ошибки приходят в том же JSON-формате, но с другим статусом:

- `400 Bad Request` — дата не соответствует формату `YYYY-MM-DD` или не существует (например, `2024-02-30`);
- `405 Method Not Allowed` — использован метод, отличный от `GET`.

В обоих случаях тело — `{"error": "<описание>"}`.
